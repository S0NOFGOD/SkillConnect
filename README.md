# SkillConnect

SkillConnect is a full-stack platform that connects nearby local skilled workers with nearby clients.

## Main Features

- Worker registration and authentication
- Client registration and authentication
- Worker profiles
- Nearby worker search
- Chat
- Booking
- Payments
- Ratings and reviews
- Notifications
- Worker verification
- Admin management

## Technology Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- SQLite
- Git
- GitHub
